 Frozen Lake Game using Q-Lear
 Project Overview

This project demonstrates the implementation of the **Q-Learning Reinforcement Learning algorithm** using the **FrozenLake-v1** environment from the Gymnasium library.

The objective is to train an intelligent agent that learns the safest path from the starting position to the goal while avoiding dangerous holes. Initially, the agent has no knowledge of the environment and gradually improves its performance through trial and error.



Objectives

- Create the FrozenLake environment.
- Initialize the Q-Table.
- Train the agent using the Q-Learning algorithm.
- Compare the trained agent with a random agent.
- Visualize training rewards.
- Calculate and analyze the success rate.
